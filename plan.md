# План створення сайту Software and Computer Museum

Оновлено: 31 жовтня 2026. Перша версія плану описувала весь сайт; друга (затверджена) деталізувала збирання головної сторінки за прототипом і дизайн-системою «Сайт музею». Нижче обидві частини разом, зі статусом виконання.

## Context
ТЗ v3 (30.10.2026) описує головну сторінку як початок редизайну sncmuseum.org: курси, екскурсія, експонати, історія, новини, адреса з картою. Вимоги: UA/EN, мобільна версія від 320px, WCAG 2.1 AA, єдина дія «зателефонувати 067 539 4095».

Підхід: статичний сайт на чистих HTML/CSS/JS без збірки. Сторінка переважно статична, інтерактив мінімальний (меню, перемикач мови, карта). Токени придатні для інших сторінок.

## Статус
- **Зроблено (етап 1, головна):** кроки 2–8 плану нижче (матеріали, токени, компоненти, секції, i18n, адаптація), часткова перевірка. Деталі в `handoff.md`.
- **Не зроблено:** вбудована карта (крок 7), повна перевірка доступності (крок 9), етап 2 (крок 10).
- **Блокує:** відкриті рішення замовника (розділ нижче).

## Порядок робіт
1. ○ **Закрити блокуючі рішення**: пара кольорів, провайдер карти, шрифти, винятки жовтого акценту, курси 40+ і підлітків, кількість експонатів. Поки діють значення з ТЗ і токенів.
2. ✓ **Матеріали**: фото й логотипи скопійовано з прототипу в `assets/img/` зі змістовними назвами. Залишилось: окреме фото для «Про музей» (зараз дублює фото першого екрана).
3. ✓ **Токени й база**: `tokens.css`, `base.css` (фокус 3px, reduced-motion, мобільні розміри заголовків).
4. ✓ **Компоненти**: кнопки, кругла кнопка дзвінка (`tel:+380675394095`, 56px на смартфоні), шапка з меню та перемикачем, картки, підвал, логотип.
5. ✓ **Секції головної**: шапка → перший екран з друком заголовка → курси (3) → екскурсія → 6 експонатів → історія → новини (3) → адреса й карта → підвал.
6. ✓ **i18n**: тексти UA/EN, перемикач змінює `lang`, вибір зберігається. Англійські тексти треба перевірити носієм.
7. ◐ **Карта**: запасний блок з адресою, метро й посиланням «Відкрити в картах». Вбудований iframe додати після вибору провайдера.
8. ✓ **Адаптація**: breakpoints 900/600px, без горизонтальної прокрутки від 320px (перевірено на 320, 375, 800, 1280px), шапка на телефоні в два рядки.
9. ◐ **Доступність і перевірка**: контраст hero розраховано (4.89:1 при 85% затемненні). Не перевірено: клавіатура, фокус, масштаб 200%, reduced-motion.
10. ○ **Етап 2**: `exhibits.html`, юридичні сторінки, реальні соцмережі, «Підтримай музей», 404, окремі мобільні підсторінки.

## Рішення, прийняті при збиранні
- Один адаптивний `index.html` для комп'ютера й телефона.
- Жовтий акцент лише на кнопках запису й круглій кнопці дзвінка; «Усі експонати» синя.
- Додано кнопку «Записатися на курс».
- Затемнення фото першого екрана 85% (`--hero-veil`) замість 60%.
- Заголовки за токенами; на екранах до 380px `display-xl` 28/34.
- Кількість експонатів: «понад 300».

## Розбіжності між макетом і дизайн-системою (вирішено на користь токенів)
Заголовки (h1 44/52, h2 вага 700, h3 24/32), тінь картки 2px у спокої, текст описів 18px. Жовтий акцент у макеті стояв і на інших елементах, у сторінці лишено за токенами.

## Критичні файли
`index.html`, `css/tokens.css` (єдине джерело значень дизайну), `js/i18n.js` (усі англійські тексти).

## Верифікація
Локальний сервер у корені проєкту (`python -m http.server 8765 --bind 127.0.0.1`), сторінка `http://127.0.0.1:8765/index.html` у панелі браузера; через `file://` стилі не підвантажуються.
- ✓ Розміри 320 / 375 / 800 / 1280px без горизонтальної прокрутки.
- ✓ Перемикач UA/EN і `lang`, єдиний номер `tel:`.
- ✓ Контраст тексту на hero.
- ○ Tab по всій сторінці з видимим фокусом.
- ○ Емуляція prefers-reduced-motion; масштаб 200%.
- ○ Карта: завантаження й запасний блок.

## Відкриті рішення (потрібні від замовника)
Пара кольорів; провайдер карти; шрифти (Google Fonts чи локально); чи залишати жовтий акцент на кнопці екскурсії; курси 40+ і для підлітків; кількість експонатів; наявність SVG-логотипа; тексти кнопок запису; реальні посилання підвалу; перевірка англійських текстів.
